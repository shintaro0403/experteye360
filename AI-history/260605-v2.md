## 3. フェーズ 3 — 実 GAS 自動テスト（opt-in）の拡張

### real-sheet E2E（`e2e/real-sheet-api.spec.ts`）を 1 → 5 本に拡張

1. preflight: 実 GAS・研修コード・管理者 token が有効
2. 別 client / 別 room に E2E 回答を返さない
3. 研修コード変更後は旧コード拒否・新コード OK（最後に元へ戻す）
4. 管理者コード変更後は旧 token 拒否・新 token OK（最後に元へ戻す）
5. `responses/clear` は当該 room の E2E 回答を削除する

`test.beforeAll` で総合プリフライト。テストは**非破壊**（変更系は最後に初期値へ復元）。

### 補助スクリプト / 共有定数

- `scripts/real-sheet-preflight.mjs`（`npm run preflight:real-sheet`）— env 設定と実 GAS 到達性、初期データ（settings / rooms verify / responses）を事前診断。
- `shared/src/demoCredentials.ts` — デモ資格情報を一元化。
  - Sheet: `lipronext-demo` / `demo-room-001` / `demo-2026` / `admin-demo-2026`
  - local: `DEMO-2026` / `admin-demo`
- `admin-web/src/pages/AdminPage.tsx` — Sheet backend では研修コード平文を保存しないため、入力欄は初期空・プレースホルダー「新しい研修コード（変更時のみ入力）」。

### GAS（`gas/Code.gs`）に復元関数追加

| 関数 | 用途 |
|------|------|
| `resetDemoTrainingCode()` | 研修コードを `demo-2026` に戻す（hash のみ更新） |
| `resetDemoCredentials()` | 管理者コード + 研修コードを初期値へ一括復元 |

> セッション中、ユーザーが GAS をバージョン 5（`AKfycbwIo5h00...`）として新規デプロイし、URL 更新・関数実行を実施。

### バグと修正（重要）

- **`smoke:phase1-sheet` が破壊的だった**: access-code プローブが実シートの研修コードを `__smoke-probe-do-not-use__` に書き換え、以後の preflight / E2E が「Invalid training code」で skip。

## 4. フェーズ 3 完了確認で mock E2E 4 件赤 → 現 UI 追従修正

完了判定のため `npm run test:e2e`（mock）を実行したところ `participant-admin-flow.spec.ts` が 4 件失敗。**実機能の不具合ではなく、UI 仕様変更にテストが追従していなかった**ことが原因。

| 失敗 | 原因 | 修正（spec 側） |
|------|------|-----------------|
| 受講者フロー 2 件 | 名前・所属の「10 文字以内」制限（`validateStep.ts`）に違反 | `Phase4 テスト所属`→`Phase4所属`、`Phase4 共有確認`→`Phase4確認` |
| 研修コード変更 | sheet モードのプレースホルダー変更 | `受講者が入力するコード`→`新しい研修コード（変更時のみ入力）` |
| 管理者コード変更 | ボタン名リネーム | `ロック`→`管理者コード入力に戻る`（2 箇所） |

修正後、`participant-admin-flow.spec.ts` 4 passed、mock E2E 全体 **6 passed / 5 skipped**（real-sheet は env 未設定で自動 skip）。

## 5. フェーズ 4 — CI へ mock E2E 搭載

`.github/workflows/ci.yml` に以下を追加（Secrets 不要）。

```yaml
- name: Install Playwright browser (chromium)
  run: npx playwright install --with-deps chromium

- name: E2E (mock, Playwright)
  run: npm run test:e2e

- name: Upload Playwright artifacts on failure
  if: failure()
  uses: actions/upload-artifact@v4
  with:
    name: playwright-results
    path: test-results/
    retention-days: 7
    if-no-files-found: ignore
```

- `timeout-minutes` を 15 → 20 に拡張。
- `playwright.config.ts` は `process.env.CI` で dev サーバー（5275/5276）と mock API（5198）を新規起動。chromium のみ。
- 実 GAS（`real-sheet-api.spec.ts`）は env 未設定で自動 skip → PR 毎の実 GAS 実行を回避。
- **結果: push 後の GitHub Actions ですべて緑（ユーザー確認）。フェーズ 4 完了。**
