### 3.4 必須バリデーション

| 項目 | 必須 | next 未入力時 |
| --- | --- | --- |
| 名前・所属 | ○ | 進まない。警告表示 |
| 気づき / 共有・行動 / 判断基準カード | ○（各 1 枚） | 同上（フェーズ別メッセージ） |
| 一言メモ | × | 空でも進める |

**実装の要点**

- `fieldWarn` state
- `validateStep()` … 現在 step の必須チェック
- `tryNext()` … エラー時 `setFieldWarn(msg)` して return、OK なら `advanceStep()`
- `goBack` / 入力・カード選択時に `setFieldWarn(null)` で警告クリア
- 旧 `goNext` 参照をすべて `tryNext` に統一（intro・各 ChipStep・NoteStep・確信度・送信）

**警告メッセージ例**

| step | メッセージ |
| --- | --- |
| intro | `名前を入力してください` / `所属を入力してください` |
| awareness | `気づきカードを1つ選んでください` |
| action | `共有・行動カードを1つ選んでください` |
| criteria | `判断基準カードを1つ選んでください` |

### 3.5 （必須）/（任意）バッジの配置

| 段階 | ユーザー要望 | 対応 |
| --- | --- | --- |
| 1 | カード step のタイトルに（必須） | `Nav` に `titleRequired`、`ChipStep` から渡す |
| 2 | タイトルの**左**に入れてしまった | 訂正依頼 |
| 3 | タイトルの**右**に（必須） | `p-step-meta__title` の**後**に `p-step-meta__badge--required` |
| 4 | 一言メモの**右**に（任意） | `titleOptional` を `NoteStep` の `Nav` に付与 |

**表示例（ナビ中央）**

```
設問 1/5 · 気づきカード（必須）
設問 1/5 · 一言メモ（任意）
```

intro の入力欄ラベルは従来どおり「名前（必須）」「所属（必須）」。一言メモの textarea 上ラベルにも「（任意）」を維持。

| step | 内容 |
