## 4. 会話の経緯（時系列）

### 4.1 文脈引き継ぎ

- `260516-v1.md` と `TECHNICAL-SPEC.md` を読み、lite 廃止・React のみ・25% 帯・container query（`cqh`/`cqw`）前提を継承。

### 4.2 intro（step 0）

- **高さ**: `.p-intro-card` を `.p-body` 内 **60%**（`height: 60%`）。
- **フォント**: カードに `font-size: clamp(1rem, 6.5cqh, 1.65rem)`。ラベル・入力・select・next は `em` で連動。
- **注意**: カードに `container-type: size` を付けると `cqh` がカード基準になり文字が小さくなるため **付けない**（embed `.p-shell` 基準）。
- next はのち **ネイビーバー**へ移動（カード内ボタン削除）。

### 4.3 選択カード（`.p-chip`）

#### 初期不満

**内容** — 文字小さい、横幅余る、縦長トレカ（5:7）

#### 横長化

**内容** — `flex: 1 1 0` で 5 枚均等、`aspect-ratio` 廃止、`align-items: stretch`

#### `p-chip__art`

**内容** — ユーザー指示で **削除**（TSX・CSS）

#### 高さ調整

**内容** — 大→小→中間→80%→**元に戻し**（`min-height: clamp(2.75rem, 48cqh, 5.75rem)`、`height: 100%`）

#### 色

**内容** — **通常**: 白背景・紺文字。**ホバー**: 紺背景・白文字（反転）

#### 選択

**内容** — **単一選択**（`selectSingle`）。**選択中も反転維持**

#### ホバーと選択

**内容** — 未選択カードホバー中は選択済みを一旦通常色に（反転は同時に1枚）

**カード高さを変える場所**（説明済み）:

```css
/* shared/styles/participant-app.css */
.p-chip {
  height: 100%;
  min-height: clamp(2.75rem, 48cqh, 5.75rem);
}
```

親 `.p-chips`（`flex: 1`）が縦スペースを渡す。枠は `.p-chip__frame` の `height: 100%`。

### 4.4 ヘッダー・進捗の削除

- `<header className="p-strip__head">` 一式（ブランド・`p-progress`・`p-caption`）を削除。
- `STEPS` 定数も削除。

### 4.5 ネイビーバー（`.p-nav-bar`）

- カード（またはフォーム）**直下**、フォーム最下部（`margin-top: auto`）。
- バー内右端: **back**（ゴースト・白枠）、**next**（白背景・紺文字）。
- ラベルは「戻る」「次へ」から **back** / **next** に変更（intro・各 step）。
- 送信完了画面は `p-nav--center` のまま（バー拡大スタイルは適用しない）。

### 4.6 一言メモのフロー変更

- 一問目（step 1）の `next` → **step 2（メモ）** → step 3（二問目）。
- step 2 から気づきカード＋`awarenessNote` を分離；気づき画面にメモ欄 **なし**。
- 型: `attentionNote: string` を `shared/src/types.ts` の `ParticipantSubmission` に追加。
- 送信時 `awarenessNote: ""`（後方互換フィールドは維持）。

### 4.7 一言メモ画面（step 2）の見た目

#### 文字

**指定** — 小さい → `clamp(1rem, 6.5cqh, 1.65rem)` 基準、placeholder も同スケール

#### 記載欄

**指定** — でかすぎ → **幅 80%** 中央、**高さは以前の 80%**（`clamp(2.4rem, 22.4cqh, 4.8rem)`）

#### placeholder 例

**指定** — `例：配管の振動が気になった`

#### CSS

**指定** — `.p-form--note`、`.p-form--note .p-field--note`

## 7. 技術メモ

- **container query**: 帯全体は `.p-shell` の `container-type: size`。intro のフォントは **shell の cqh** を使う。
- **チップの cqw 上限**: 旧 `2.4cqw`＋`max 0.72rem` は横長 PC で文字が小さくなる原因だった → **cqh 中心**に変更済み。
- **単一選択**: `selectSingle` で配列は 0 または 1 要素。判断 step も `syncCriteriaOrder([l])` または `[]`。
- **ホバー反転の競合**: `.p-chips:has(.p-chip:not(.p-chip--on):hover) .p-chip--on:not(:hover)` で選択済みを一時通常色。
