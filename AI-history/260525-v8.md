# 260525-v8

## この回で進めたこと

- GAS Web App を前提に、`VITE_STORAGE_BACKEND=sheet` で受講者・管理者画面が Sheet API を使うように配線した。
- 既存の localStorage 同期 API は残し、画面側は `shared/src/storage.ts` の async API（`loadSettingsAsync` / `saveSettingsAsync` / `appendResponseAsync` など）を使う形へ変更した。
- 受講者の研修コード検証は `rooms/verify`、回答送信は `POST responses` を使う。
- 管理者コードは Sheet API の `token` として扱い、`GET responses` による検証、`POST settings` による設定保存、`POST admin/token` による管理者コード変更を行う。
- GAS の routing は `/exec/settings` ではなく `?path=settings` 形式で統一した。

## 変更した主なファイル

- `shared/src/storage.ts`
  - local / sheet 切替と async storage API を追加。
  - Sheet backend の設定読込、設定保存、回答読込、回答追加、研修コード検証、管理者 token 変更を追加。
- `shared/src/adminEntry.ts`
  - Sheet backend 用に管理者 token を `sessionStorage` へ保持するヘルパーを追加。
- `participant-web/src/hooks/useAppData.ts`
- `admin-web/src/hooks/useAppData.ts`
  - 初期 local 読込 + async refresh に変更。
  - `loading` / `error` を返すようにした。
- `participant-web/src/pages/ParticipantPage.tsx`
  - 研修コード検証と回答送信を async API 経由へ変更。
- `admin-web/src/pages/AdminPage.tsx`
  - Sheet backend 時は管理者コードを API token として検証。
  - 設定保存・回答取得・管理者コード変更を Sheet API 経由へ変更。
  - Sheet backend では未実装の「研修コード変更」「全回答削除」は明示的に案内する。
- `gas/README.md` と `docs/*`
  - GAS / Sheet API / `VITE_STORAGE_BACKEND=sheet` が最小実装済みであることに更新。
