## 1. TDD — 管理者コード変更（Sheet backend）

### 目的

管理画面で管理者コードを変更・保存できない問題を直す。特に「現在欄」未入力や不一致のまま API に誤った `token` が渡るのを防ぐ。

### 受け入れ条件 / 成功条件

- ログイン済みセッションの `adminToken` で API を呼ぶ（URL の `token` は再入力欄の文字列そのものではない）。
- 「現在の管理者コード」はセッション token と一致したときだけ変更可能。空・不一致は API 前に拒否。

### テスト

- `shared/src/adminEntry.test.ts` — `validateSheetAdminCodeChange`（空・不一致・短い新コード・同一・成功）
- `admin-web/src/pages/AdminPage.test.tsx` — Sheet モックで UI 操作 → `changeAdminTokenAsync` の引数とメッセージ

### Red → Green

- Red: 現在欄が空 / 不一致でも `changeAdminTokenAsync` が呼ばれていた。
- Green: `validateSheetAdminCodeChange` を `adminEntry.ts` に追加。`AdminPage.saveAdminCodeChange` で検証後 `changeAdminTokenAsync({ adminToken, nextAdminToken })`（セッション token）。

### 変更ファイル

- `shared/src/adminEntry.ts` / `adminEntry.test.ts`
- `admin-web/src/pages/AdminPage.tsx` / `AdminPage.test.tsx`

## 3. GAS デプロイ・マスター ID 設定（トラブルシュート）

### 症状

新しいデプロイ URL に `.env` を更新後:

```json
{"ok":false,"status":500,"error":"Master spreadsheet id is not configured"}
```

### 原因

**新しい GAS プロジェクト**で `setupDemo()` または `linkMasterSpreadsheet` を実行していない。デプロイだけではスクリプトプロパティ `EXPERTEYE360_MASTER_SPREADSHEET_ID` は付かない。

### ユーザー対応（セッション内で完了）

1. Drive の **ExpertEye360 Master** のスプレッドシート ID を取得（URL の `/d/【ID】/edit`）。
2. Apps Script の `Code.gs` に `LINK_MASTER_SPREADSHEET_ID` と `runLinkMyMaster()` を追加して実行。
3. `logScriptPropertyStatus` → ログ `OK: MASTER_ID=...`。
4. 管理者コード `admin-demo-2026` が通らない → `resetDemoAdminToken()` 実行で hash を初期値に復帰。

### GAS Code.gs に追加した運用関数

| 関数 | 用途 |
|------|------|
| `linkMasterSpreadsheet(id)` | 既存マスター ID をスクリプトプロパティに設定 |
| `runLinkMyMaster()` | エディタから引数なしで実行（`LINK_MASTER_SPREADSHEET_ID` 定数に ID を貼る） |
| `logScriptPropertyStatus()` | キー設定済みかログ確認 |
| `resetDemoAdminToken()` | 管理者コードを `admin-demo-2026` に戻す |

| v3 | `AKfycbyfOsvcQ...` | ユーザーが新規デプロイ。マスター紐付け後 Green |
