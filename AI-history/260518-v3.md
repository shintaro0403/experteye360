### 2.2 可変レイアウト・25% まわり（重要）

| ユーザー指摘 | 内容 |
| --- | --- |
| 可変しなくなった | 画面高を変えても収まるようにしてほしい（以前の要望） |
| 25% でコンテンツがはみ出す | **25% は 3DVista 側のフレーム比率**。アプリは **iframe 内 100%×100%** で組むべき。`25vh` や大きな `rem` 下限で固定サイズ化していた |
| 仕様書を毎回書くな | **明示依頼がない限り `docs/` を更新しない**（本セッション中に AI が `TECHNICAL-SPEC.md` §3.2.3、`TEST-DESIGN.md` §8.1 等を追記 → ユーザー強い不満） |

**AI が行った CSS 方針の修正（コード側）**

- `.p-shell` を基準に `cqh`/`cqw` でスケール（`vh` は使わない）
- `clamp(1rem, …)` など **大きな rem 下限**を縮小または `min(Ncqh, rem)` に変更
- intro を `height: auto` + 小さすぎる `max-height` にした状態から、**帯に収まりつつ縮む**方向へ再調整
- CSS 先頭コメントに「iframe 100% 基準・25% はホスト側」と記載

**ユーザー**: 「もうこっちで治す」→ 以降はユーザー側での調整もあり得る。

## 3. 現行 CSS の要点（セッション終了時点）

### 3.1 `.p-shell` の CSS 変数

```css
--p-font-lg: clamp(0.55rem, 6.5cqh, 1.65rem);
--p-font-chip: clamp(0.55rem, 6.5cqh, 1.45rem);
--p-note-min-h: max(26cqh, calc(2.7em + 6cqh));
--p-note-h: clamp(26cqh, 34cqh, 5.5rem);
--p-intro-card-min: clamp(10rem, 52cqh, 100%);
```

### 3.2 intro（step 0）

```css
.p-body:has(.p-form--intro) { padding-top: 0; }

.p-form--intro {
  display: grid;
  grid-template-rows: minmax(0, 1fr) minmax(var(--p-intro-card-min), auto) minmax(0, 1fr) auto;
  padding-top: var(--p-body-pad-top); /* 旧 p-body 上 padding */
}

.p-form--intro .p-intro-card { grid-row: 2; height: 100%; … }
.p-form--intro .p-nav-bar { grid-row: 4; }
```

- **1 行目・3 行目**（`1fr`）: カードの**上・下**の余白を等分
- **2 行目**: カード（最低 `52cqh`）
- **4 行目**: ネイビーバー
- `.p-body` の上 padding はフォーム先頭へ移し、二重にならないようにした

### 3.3 記載欄（`.p-form--note`）

- 幅 80%、フォント `--p-font-lg`
- テキストエリア: `min-height: max(var(--p-note-min-h), var(--p-note-h))`、`flex: 1` で帯内の余白まで伸びうる

### 3.4 intro 内入力

- `.p-field--compact .p-field__input`: `flex: 1 1 0`、`min-height: max(12cqh, calc(1.35em + 4cqh))`

## 6. ハマりどころ・教訓

1. **`height: auto` + 大きな `clamp` の rem 下限** → 帯が低いときはみ出し、高いときは意図より小さく見える。
2. **`margin-top: auto` だけ**では `.p-body` の `padding-top` 分だけ上が太く見える。
3. **カードに `flex: 1` と `margin: auto` を同時** → 余白が潰れてカードが帯いっぱいになることがある。
4. **仕様書の自動更新** → ユーザー作業フローを妨げる。**依頼時のみ**が正しい。
5. **25%** は説明用の配置比率。**実装の基準は iframe の container（`.p-shell`）**。
