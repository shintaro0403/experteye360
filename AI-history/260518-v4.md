### 3.2 intro の高さ・余白

| 段階 | ユーザー要望 | 対応 |
| --- | --- | --- |

### 3.3 ナビバー・ボタン（ユーザー強い指摘）

| 問題 | 原因 | 対応 |
| --- | --- | --- |
| intro と設問でナビの高さが違う | step0 のみ grid 4 行、設問は flex + `auto` 行、intro は `p-body` の下 padding なし | 設問も **grid 最下行 = `--p-nav-h`**。intro に **`--p-nav-bottom-gap`** を適用 |
| back/next が潰れる | `height: 72%` + `padding: 0` | **`--p-nav-btn-h`** を calc で固定 |
| 一言メモの余白がない／のち極端に小さい | `flex:1` + `max-height: min(...)` で縮小 | **`--p-note-gap` + `--p-note-block-h`** の 4 行 grid、textarea はブロック内 100% |

### 3.4 ナビ下端の揃え

- 設問は `.p-body` の `padding-bottom` でナビ下に隙間があった。
- intro だけ `padding-bottom: 0` → **全 step 共通で `--p-nav-bottom-gap`**（`p-body` 下 padding に使用）。intro は上 padding のみ 0。

## 4. レイアウト変数早見（`.p-shell` 64〜79 行付近）

**ここだけ変えればよい**（2026-05-18 終了時点の値）。

| 変数 | 値（例） | 意味 |
| --- | --- | --- |
| `--p-nav-h` | `25cqh` | ナビバー高さ（全 step） |
| `--p-nav-pad-block` | `4cqh` | ナビ内上下 padding |
| `--p-nav-btn-h` | calc | ナビ内ボタン高さ |
| `--p-nav-bottom-gap` | clamp(...) | ナビ下・帯下端の余白 |
| `--p-intro-gap` | `8cqh` | step0 白枠の上・下余白（最小） |
| `--p-intro-card-h` | `52cqh` | step0 白枠の高さ |
| `--p-intro-card-w` | `88%` | step0 白枠の幅 |
| `--p-intro-field-h` | `36%` | 白枠内入力（枠内 %） |
| `--p-note-gap` | `7cqh` | 一言メモ上下余白（最小） |
| `--p-note-block-h` | `42cqh` | 一言メモブロック高さ |
| `--p-content-gap` | `6cqh` | 選択カード上下 padding |

単位 **cqh** = 埋め込み帯（`.p-shell`）の高さに対する比率。25% は 3DVista 側の話で、アプリは iframe **100%×100%** 前提。
