### 追加したテスト

#### `participant-admin-flow.spec.ts`

- 受講者が研修コードを入力し、名前・所属、5 問、確信度、送信完了まで進める
- 受講者が送信した回答を管理者が回答一覧で確認できる

#### `embed-layout.spec.ts`

- 受講者 iframe が 25% 帯の中でアプリを 100% 表示する
- 管理者 iframe が 40% パネルの中でアプリを 100% 表示する

### Red 確認

最初の E2E 実行では、想定どおり `5173` の受講者送信が `5174` の管理者回答一覧に共有されず Red になった。

```text
3 passed / 1 failed
failed: 受講者が送信した回答を管理者が回答一覧で確認できる
```

失敗理由:

- 現状の保存先は localStorage
- `participant-web`（5173）と `admin-web`（5174）は別オリジン
- そのため回答が自動共有されない

## 5. Phase 4 の最小実装

ユーザー指示:

> 次はテストが通る最小限の実装を入れてください

本番 Sheet API 実装には踏み込まず、Phase 4 E2E を通すための開発補助として E2E 用共有ストレージを追加した。

### 追加したファイル

- [scripts/e2e-storage-server.mjs](../scripts/e2e-storage-server.mjs)

### 更新したファイル

- [shared/src/storage.ts](../shared/src/storage.ts)
- [shared/src/storage.test.ts](../shared/src/storage.test.ts)
- [playwright.config.ts](../playwright.config.ts)
- [e2e/participant-admin-flow.spec.ts](../e2e/participant-admin-flow.spec.ts)

### 実装内容

- Playwright 実行時だけ使うローカル共有ストレージサーバーを追加
- `navigator.webdriver` かつ `127.0.0.1` のときだけ、`shared/src/storage.ts` が回答一覧を E2E 用サーバーへ同期
- 通常の localStorage 実装は維持
- Playwright の `webServer` に participant / admin / E2E storage server を登録
- `test-results/` / `playwright-report/` を `.gitignore` に追加

### 注意

この E2E 用共有ストレージは本番仕様ではない。Sheet API が本配線されたら、Playwright も Sheet API dev / mock 経路へ置き換える前提。
