### 3.2 入室・マルチテナント（D-06 / D-07 / D-08）

#### `clientId`

**誰** — 両方
**役割** — URL `?client=`。マルチテナント最上位

#### **研修コード**

**誰** — 受講者
**役割** — **名前・所属より前**に入力。`rooms` と照合

#### **管理者コード**

**誰** — 管理者
**役割** — 入室必須。**研修コードは不要**（設定する側）

#### `roomId`

**誰** — 受講者（検証後）
**役割** — `sessionStorage` 保持。API の `room` に使用

**受講者 UI フロー**

1. 研修コード入力
2. 成功 → 名前・所属表示 → 5 問フロー
3. 失敗 → **「正しい研修コードを入力してください」**（名前・所属は出さない）

**管理者**

- 入室: **管理者コード**のみ
- 研修コードは「ツアーURL」タブで **受講者向けに設定**
- **管理者コード変更**は現行コードの再入力必須

**ローカル開発（D-07）**

- **本番近似**: 入室ゲートを省略しない方針（ドキュメント）。実装は `localStorage` + settings 内の `rooms` / `adminAccessCode`

**未決定（残置）**

- **D-21**: 管理者の回答一覧と `room` 絞り込み（全 room / UI 選択のみ 等）

- 5173（受講者）と 5174（管理者）は **別オリジンの localStorage**
- 管理者が研修コードを変更しても、受講者側 settings は自動同期されない → 受講者は再読込または同一シード前提で確認
- 本番は Sheet API で統一予定
