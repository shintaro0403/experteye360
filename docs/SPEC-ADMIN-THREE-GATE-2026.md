## 1. 目的

- **URL は全員共通**。データの分離は **コードのみ**（URL・`client` 以外の秘密パスに頼らない）。
- 管理者は **3 つの画面を順に突破**しないと次に進めない。
- **研修コードは②の単独画面だけ**で入力する。③に研修コード入力欄を **出さない**（タブの一部としても出さない）。
- **1 研修コード = 1 管理画面（room）**。コードが違えばシーン・カード・回答もすべて別。
- 受講者は、**その room に紐づく研修コード**で入室した回答だけが、③の回答タブに表示される。

---

## 2. プロダクト方針（ブレ禁止）

1. **管理者コード（共有・デモ）** — 「研修コードを入力していい権限」だけ与える。①を突破すると②へ。**③のタブはまだ出さない**。
2. **研修コード（②）** — 操作・閲覧する **研修回（room）を確定**する。②を突破すると③へ。**②以外の画面に研修コード入力欄を置かない**。
3. **管理画面（③）** — room 確定後のみ。基本 / シーン・カード / 回答のタブを出す。
4. **受講者研修コード** — room の `accessCode`（シート／設定上の値）。**③の UI から変更・保存する機能は出さない**（本仕様のスコープ外）。
5. **出さない UI** — 管理者コード変更、3DVista ツアー URL 編集（従来どおり）。

## 3. 3 画面の定義

### ① 管理者コード画面

| 項目 | 内容 |
|---|---|
| **目的** | 共有管理者コードの照合。通過で②へ。 |
| **表示** | 管理者コード入力のみ。 |
| **非表示** | 研修コード欄、基本 / シーン・カード / 回答タブ、回答一覧、シーン編集。 |
| **主ボタン** | `続ける`（デモ `adminRoomScope: trainingCode` 時） |
| **DOM 目印** | `data-admin-phase="admin-code"` |

### ② 研修コード画面（ゲート）

| 項目 | 内容 |
|---|---|
| **目的** | 操作対象 room の確定（未登録コードは新規 room 作成）。通過で③へ。 |
| **表示** | 研修コード入力のみ。見出し `研修コード`。 |
| **非表示** | 管理者コード欄、**すべての管理タブ**（基本・シーン・カード・回答）、回答・シーンの中身。 |
| **主ボタン** | `入室する` |
| **副ボタン** | `管理者コード入力に戻る` → ①へ（ゲート・room セッションをクリア） |
| **DOM 目印** | `data-admin-phase="training-gate"` |
| **禁止** | `.a-tabs` の存在。タブ相当のナビを DOM に出さない。 |

### ③ 管理者画面（workspace）

| 項目 | 内容 |
|---|---|
| **前提** | ②で `roomId` 確定済み。 |
| **表示** | タブ: 基本 / シーン・カード / 回答。初期タブは **基本**。 |
| **基本タブ** | **研修回の表示のみ**（例: 操作対象の表示名）。**研修コード入力・保存 UI は出さない**。 |
| **非表示** | 管理者コード変更、ツアー URL 編集、**研修コードを保存** ボタン、**次の研修コード** 入力欄。 |
| **DOM 目印** | `data-admin-phase="workspace"` |

## 4. ゲート規則（突破しないと次を見せない）

| 遷移 | 条件 |
|---|---|
| ① → ② | 管理者コードが正しい。②入室時に **旧 workspace セッション（auth + roomId）を必ずクリア**。 |
| ② → ③ | 研修コードを入力して `入室する`。既存 room があればその room へ、**未登録なら新規 room を作成**して `roomId` をセッションに保存（管理者が研修コードを決める）。 |
| ③ → ① | `管理者コード入力に戻る` で全セッションクリア。 |

**セッション契約（コード上の期待値）**

- ゲートのみ: `gate=1`, `token` あり, `auth` なし, `roomId` なし → **workspace ではない**
- ③入室: `auth=1`, `token` あり, `roomId` あり, `gate` なし → **workspace**
- `isAdminWorkspaceActive()` は **ゲート中は常に false**（不整合セッションでも③を出さない）

---

## 5. room と回答の分離

- 管理者が③で見る回答は **`session.roomId` と一致する `submission.roomId` のみ**。
- 例: 研修コード `2001` の room で保存された回答は、研修コード `0403` で入室した③には **表示しない**。
- localStorage バックエンドでも Sheet API と同様に **room フィルタ必須**（全件返却禁止）。
